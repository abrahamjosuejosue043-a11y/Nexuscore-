Acesso administrativo

Informe o token uma vez. O servidor cria uma sessão protegida por cookie, válida por 48 horas. O token não fica salvo no navegador nem acessível ao JavaScript.

Diagnóstico detalhado

Execute o diagnóstico para verificar as conexões.

Limites conhecidos do ambiente

A Groq oferece análise visual, OCR e interpretação de imagens, mas sua API não gera imagens a partir de texto. O Nexuscore não usa outro provedor para geração de imagens. O serviço está no plano gratuito do Render. A persistência está configurada no Neon PostgreSQL; confira o estado da conexão no diagnóstico detalhado. Os perfis de Diretoria, Engenharia e Marketing usam instruções diferentes, mas ainda não formam uma cadeia multiagente autônoma.
