Limites conhecidos do ambiente

A Groq oferece análise visual, OCR e interpretação de imagens, mas sua API não gera imagens a partir de texto. O Nexuscore não usa outro provedor para geração de imagens. O serviço está no plano gratuito do Render. O banco SQLite local é temporário e pode perder dados em reinicializações ou novos deploys. Os perfis de Diretoria, Engenharia e Marketing usam instruções diferentes, mas ainda não formam uma cadeia multiagente autônoma.

Nexuscore AI · Interface operacional · Não compartilhe chaves de API ou senhas no chat.
